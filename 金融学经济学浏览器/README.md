# 📊 金融学经济学浏览器

> 为金融学、经济学专业学生打造的 macOS 学习浏览器
> Swift + AppKit + WKWebView ｜ macOS 12.0+

---

## ✨ 简介

一款**面向金融与经济专业**的浏览器，深色交易大厅风格，内置市场数据、学术研究、投资工具。由**中国人民大学强基计划古文字学专业学生**严小焕开发（跨学科作品）。

## 📈 设计理念：数字交易室

- 深色交易面板 + 涨绿跌红，专业金融终端观感
- 全球股指滚动条实时模拟
- 自动跟随 macOS 深浅色（浅色为专业灰度）

## 🧩 功能总览

| 模块 | 说明 |
|------|------|
| 📈 行情滚动条 | 13 个全球指数（道指/纳指/上证/恒生/BTC/黄金等），涨绿跌红 |
| 🎯 智能磁贴 | 25 个金融网站，8 大方向（行情/宏观/外汇/固收/加密/新闻/学术/监管）一键筛选 |
| 🔍 智能搜索 | `600519`→东财行情、`AAPL`→Yahoo、6 引擎切换 |
| 🌐 整页翻译 | Google 翻译代理，中英双向 |
| 🖱 右键工具 | 金融术语翻译 / 缩写展开 / 数量级换算 / 汇率换算 / 金融搜索 |
| 🧮 金融计算器 | 复利终值 / 贷款月供 |
| 📅 经济日历 | 美联储议息 / 非农 / CPI / 央行决议 |
| 📚 经典金融著作 | 国富论 / 通论 / 资本论等 10 部 |
| 🛡️ 安全 | 广告拦截 + 防搜索劫持 + UA 伪装 |

## 🖱 选中文字右键（金融利器）

```
🔍 财报查询 / K线图 / 相关新闻 / 经济指标 / 学术论文
🌐 翻译（金融领域）    —— duration→久期、equity→权益 等术语纠正
📖 展开缩写 / 查术语    —— GDP / CPI / FOMC / EBITDA / ROE 等 24 条
🔢 换算数量级           —— $1.2 billion → 12 亿
💱 按汇率换算           —— USD/CNY/EUR/JPY/HKD/GBP 六币种
```

## ⚡ 自动增强

- **术语悬浮气泡**：悬停 `duration` `leverage` 等金融词自动显示中文
- **公式渲染**：SSRN / RePEc / NBER 自动加载 MathJax
- **汇率缓存**：1 小时 TTL + 断网回退
- **翻译缓存**：7 天 TTL

## 🔨 构建

```bash
cd 金融学经济学浏览器/source
swiftc -target arm64-apple-macosx13.0 -sdk $(xcrun --show-sdk-path) \
  -framework Cocoa -framework WebKit -O \
  -o "金融学经济学浏览器.app/Contents/MacOS/金融学经济学浏览器" \
  main.swift AppDelegate.swift FinanceData.swift
```
