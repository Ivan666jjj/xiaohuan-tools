# 📊 金融学经济学浏览器 · 使用说明

> 面向金融学 / 经济学专业用户的 macOS 浏览器
> 版本：1.0 ｜ 系统要求：macOS 12.0+

---

## 一、安装

1. 打开桌面上的 `金融学经济学浏览器.dmg`
2. 将 **金融学经济学浏览器** 拖入「应用程序」文件夹
3. 首次打开如提示"无法验证开发者"，右键图标 → 打开 → 再点「打开」

> 💡 也可以不拖入应用程序，直接在 DMG 里双击运行（配置保存在用户目录，不受影响）

## 三、核心功能

### 3.1 智能搜索（地址栏）

| 输入 | 行为 |
|------|------|
| `600519` | 直接打开贵州茅台行情页（沪市） |
| `000001` | 直接打开平安银行行情页（深市） |
| `AAPL` / `BTC-USD` | 跳转 Yahoo Finance 行情 |
| `https://...` 或 `eastmoney.com` | 直接打开网址 |
| `通货膨胀` 等关键词 | 按所选引擎搜索（默认百度股市通） |

**切换搜索引擎**：地址栏左侧下拉，可选 百度股市通 / Google Finance / 东方财富 / 彭博 / SSRN / FRED

### 3.2 专业方向筛选

起始页顶部按钮可一键过滤磁贴：

```
全部 · 股市行情 · 宏观经济 · 外汇汇率 · 固定收益 · 加密货币 · 财经新闻 · 学术研究 · 监管与央行
```

### 3.3 选中文字右键工具（金融利器）

在任意网页选中文字 → 右键：

| 菜单项 | 功能 |
|--------|------|
| 🔍 财报查询 / K线图 / 相关新闻 / 经济指标 / 学术论文 | 按选中词跳对应金融搜索 |
| 🌐 **翻译（金融领域）** | 中英互译 + 术语对照纠正（duration→久期 等） |
| 📖 **展开缩写 / 查术语** | GDP/CPI/FOMC/EBITDA/ROE/WACC 等 24 条缩写 |
| 🔢 **换算数量级** | `$1.2 billion → 12 亿`、`$34 trillion → 34 万亿` |
| 💱 **按汇率换算** | USD/CNY/EUR/JPY/HKD/GBP 六币种对照 |

### 3.4 整页翻译（🌐 按钮）

1. 在英文财报/研报页面点击 🌐
2. 选择「翻译为中文」（或中文页面选「翻译为英文」）
3. 页面切换为 Google 翻译代理视图，**原文译文对照**，随时切回

### 3.5 自动增强（无需操作）

- **术语悬浮气泡**：鼠标悬停 `duration` `leverage` `margin` 等 15 个金融词 → 自动弹出中文释义
- **公式渲染**：SSRN / RePEc / NBER 学术站自动加载 MathJax，论文公式不再乱码
- **广告拦截**：财经网站广告自动隐藏（东方财富/同花顺/新浪财经等）
- **防搜索劫持**：拦截百度安全验证跳转，UA 伪装规避反爬

### 3.6 行情滚动条

工具栏下方黑色滚动条实时模拟全球指数（道指/纳指/标普/上证/恒生/日经/富时/DAX/BTC/ETH/黄金/美元指数），涨绿跌红，30 秒刷新。

## 六、常见问题

**Q：为什么右键菜单没有出现？**
A：必须**先选中文字**再右键（菜单是选中文本的金融工具）。在网页空白处右键是系统默认菜单。

**Q：翻译提示"服务暂不可用"？**
A：翻译走免费 API（MyMemory），偶尔限流，稍后重试。缩写查询和数量级换算完全本地，不受影响。

**Q：汇率换算没反应？**
A：首次需联网获取汇率（open.er-api.com）。之后 1 小时缓存，断网也能用缓存数据。

**Q：起始页磁贴能不能自定义？**
A：起始页「＋ 添加书签」弹窗可添加自定义网站（存 localStorage）；右键磁贴可隐藏。

**Q：金融数据需要付费吗？**
A：不需要。行情为模拟数据，搜索引擎/翻译/汇率全部用免费接口。
