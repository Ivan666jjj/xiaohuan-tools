# 🔧 小焕工具箱

macOS + Windows 桌面应用。不需要编程，下载就能用。
🪟 全新液态玻璃 UI 设计。

## 它能做什么

🌤 查天气 + 火烧云
问「北京今天适合看日落吗」，自动回答你。

📜 查汉字
输入「日」，告诉你《说文解字》怎么解释、是平声还是仄声。

🍳 生活
冰箱有鸡蛋番茄？告诉你怎么做，自动算预算。

## 怎么用

1. 需要一个 **DeepSeek API Key**（去 platform.deepseek.com 注册，充值 ¥10 够用很久）
2. 下载 App，打开，填入 Key
3. 直接打字问就行
