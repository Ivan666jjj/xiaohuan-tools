# 🔧 小焕工具箱

macOS 桌面应用。19 个 AI 技能，点开即用。

## 安装
1. 下载 `小焕工具箱.dmg`
2. 双击打开，拖到 Applications 文件夹
3. 打开即可使用

## 系统要求
- macOS 14.0+
- Apple Silicon (M1/M2/M3/M4) 或 Intel

📜 汉语言工具（说文/平仄/音韵/经学）
📝 笔记转考题、文件阅读
🍳 生活助手（菜谱/购物/健康）
🤖 半文半白写作、人类化写作
🎯 Token 自动节约
