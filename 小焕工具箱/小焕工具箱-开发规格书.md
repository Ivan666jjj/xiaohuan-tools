# 小焕 AI 工具箱 — 开发规格书

> 给 AI 看的完整开发说明。拿这个给任何 AI，都能直接开做。

## 一、项目概述

Electron 桌面应用。把 19 个 AI skill 做成独立 app，点开即用，不需要浏览器和开发者模式。

## 二、技术栈

| 工具 | 选型 | 原因 |
|---|---|---|
| GUI 框架 | **Electron 33** | 跨平台，HTML/CSS/JS |
| 前端 | 原生 HTML + CSS + JS | 不用框架，减少依赖 |
| 数据存储 | JSON 文件本地读写 | 说文/平仄数据离线 |
| 网络请求 | fetch API | 查天气用 |
| 打包 | electron-builder | 产出 .dmg 和 .app |

## 七、数据处理逻辑

### 7.1 离线查询（说文解字、平仄等）
```
用户输入 → 匹配 data/*.json → 直接返回结果 → 零延迟
```

### 7.2 联网查询（天气、火烧云）
```
用户输入 city name
  → wttr.in/Beijing?format=%C+%t+%p+%h+%w+%S+%s  (20 token)
  → open-meteo API (400 token)
  → 应用校准：GFS云量-25%，降雨概率-40%
  → 输出校准结果
```

## 九、注意点

| 注意事项 | 为什么 |
|---|---|
| preload.js 必须用 contextBridge | 安全 |
| 本地 JSON 用 fs.readFileSync 直接读 | 不用 import，避免打包麻烦 |
| 所有网络请求用 fetch | 简单可靠 |
| skill 卡片数据硬编码 | 不需要路由，省事 |
| 先做离线功能再搞联网 | 优先级：说文>天气>生活 |
