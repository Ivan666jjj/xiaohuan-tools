# 📚 小焕的学习浏览器 · 使用说明

> 文史哲专业学习浏览器 ｜ 版本 1.0 ｜ 系统要求：macOS 12.0+

---

## 一、安装

1. 打开 `小焕的学习浏览器.dmg`（或 `文史哲浏览器.dmg`），将应用拖入「应用程序」文件夹
2. 首次打开若提示「无法验证开发者」：右键图标 → 打开 → 再次点「打开」
3. 也可以直接在 DMG 中运行（配置保存在用户目录）

---

## 二、界面总览

打开后是「汝窑天青」风格起始页（清雅文人风，自动跟随 macOS 深浅色）。

| 按钮 | 功能 |
|:---:|------|

## 三、起始页（汝窑天青书房风）

### 3.1 快捷磁贴

16 个学术磁贴：搜索引擎（DuckDuckGo/必应/搜狗）+ 汉典、国学大师、小学堂、韵典网、古音小镜、书法字典、CText、古诗文网、引得市、知网、故宫、考古中国、人大。

- 点击磁贴 → 直接跳转对应网站
- 专业方向下拉（⚙ 设置）：古文字学 / 历史学 / 考古学 / 音韵学 / 文献学 / 书法 / 综合学术，自动切换磁贴组合
- 鼠标悬停磁贴 → 上浮 + 阴影；右下角 ★ 可收藏
- 拖拽磁贴可排序；右键磁贴可隐藏 / 复制链接

### 3.2 搜索框

| 输入 | 行为 |
|------|------|
| `600519` 类股票代码 | 直接打开行情页 |
| `AAPL` 类代码 | Yahoo Finance |
| `https://...` 或 `eastmoney.com` | 直接打开网址 |
| 其他关键词 | 按所选引擎搜索（搜狗/必应/Google/DDG/汉典） |

按 `⌘K` 随时聚焦搜索框。

### 3.3 每日研读

起始页顶部一句古文名言（楷体大字 + 出处），点击卡片跳转古诗文网查看解析，右上角 🔄 换一句、📋 复制。

## 四、研究工作台

### 4.1 📝 文献笔记

- 工具栏 📝 打开独立笔记窗口：左侧目录树（按日期分组）+ 右侧 Markdown 编辑器
- 自动保存（输入停止 0.8s 后）；笔记关联当前网页 URL
- 工具栏「导出」→ 选择路径 → 生成 Markdown 文件，可一键「在 Finder 中显示」
- ⚙ 设置 → 📂 笔记存储位置：可自定义笔记数据库存放文件夹，现有笔记自动迁移

### 4.2 🤖 AI 学术助手

- 悬浮面板，非激活可点击穿透，不挡阅读
- 支持古文翻译、生僻字解释、论文推荐等对话（需本地 Ollama 服务）

### 4.3 📄 PDF 阅读器

- 工具栏 📄 选择本地 PDF → 独立阅读窗口
- 支持翻页 / 缩放 / 全文搜索（高亮跳转）

## 八、常见问题

**Q：右键菜单没有弹出？**
A：必须先选中文字再右键（工具针对选中文本）。空白处右键是系统默认菜单。

**Q：AI 助手没有回复？**
A：需要本地运行 Ollama（终端执行 `ollama serve` 并拉取模型）。未启动时显示提示。

**Q：笔记存在哪里？**
A：默认 `~/Library/Application Support/WenShiZheBrowser/library.db`，可在 ⚙ 设置自定义位置。

**Q：汉典广告还有残留？**
A：拦截脚本每 3 秒扫描清理，若仍出现请确认访问的是正版 zdic.net 且未在设置中关闭广告拦截。

**Q：翻译提示服务不可用？**
A：免费翻译 API 偶有限流，稍后重试；繁简转换/字数统计为本地功能不受影响。
