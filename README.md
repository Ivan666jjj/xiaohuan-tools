macOS 桌面应用。不需要打开浏览器，不需要输各种命令，双击就能用。

## 📦 安装（30 秒）

### Mac 用户
1. 下载 `小焕工具箱-1.0.0-arm64.dmg`
2. 双击打开，把 App 拖进 Applications 文件夹
3. 打开即可使用

### Windows 用户
1. 下载 `小焕工具箱-Setup-1.0.0.exe`
2. 双击运行，一路点「下一步」
3. 安装完成后桌面会出现快捷方式
3. **配置** → 打开 App → 输入你的 DeepSeek API Key（[免费注册](https://platform.deepseek.com)，充 ¥10 能用很久）
4. **使用** → 直接打字问任何问题

## 🎯 能做什么（功能列表）

### 🌤 天气 + 火烧云
| 问法 | 你会得到 |
|---|---|
| 「北京今天适合看日落吗」 | 天气 + 火烧云概率 + 最佳机位（比如颐和园西堤） |
| 「杭州明天会下雨吗」 | 逐时预报 + 校准后的概率 |
| 「深圳湾火烧云概率」 | 30 城机位推荐内置 |

### 📜 汉语言四大工具
| 功能 | 用法示例 |
|---|---|
| 说文解字 | 输入「日」→ 告诉你《说文》怎么解释、六书类型 |
| 诗词平仄 | 输入「白日依山尽」→ 逐字标注平仄 |
| 音韵学 | 输入「江」→ 中古音 + 上古韵部 |
| 经学引证 | 输入「天行健」→ 周易原文 + 出处 |

### 🍳 生活杂项
| 功能 | 用法示例 |
|---|---|
| 菜谱推荐 | 「冰箱有鸡蛋番茄面条，2 人吃」 |
| 购物清单 | 「预算 50 元，吃三天」 |
| 健康提醒 | 「感冒了吃什么」 |

### ✍️ 写作辅助
| 功能 | 用法示例 |
|---|---|
| 半文半白 | 输入大白话 → 输出带文言味的句子 |
| 人类化写作 | 输入 AI 写的 → 输出像人写的 |
